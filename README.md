# とけいマスター ⏰ - 4さいからの とけいあそび

4歳のお子さまが、直感的に楽しく「時計の読み方」を理解できる知育Webアプリケーションです。

---

## 🌟 主な特徴

1. **4歳児に最適化したデザイン**
   - ひらがなのみ表記、大きくて押しやすい3Dボタン
   - **時と分の色分け**: 「短い針（赤）＝〜じ」「長い針（青）＝〜ふん」
   - 針を指やマウスでくるくる回せる直感的なSVG時計
2. **生活リズムと時間の連動**
   - 朝7時は朝ごはん、12時はお昼ごはん、3時はおやつ、8時はねんねなど、かわいいイラストとお題で生活習慣と時間を結びつけます。
3. **音声読み上げ＆効果音**
   - 「3じ だよ！」「せいかい！」「おしい！ もういっかい！」など日本語音声で優しくガイド。
   - ピンポーン！の正解音と紙吹雪で達成感を高めます。
4. **3つのあそびモード**
   - ❓ **なんじかな？**: 時計を見て3択から選ぶクイズ
   - 🎯 **あわせよう！**: お題の時間に針を回して合わせるゲーム
   - 🌈 **じゆうにあそぶ**: 針を自由に回すとデジタル時間や生活イラストが変わる探求モード
5. **PWA（スマホのホーム画面追加）対応**
   - スマホやタブレットで「ホーム画面に追加」すると、アプリとして全画面で快適に遊べます。オフラインキャッシュも完備。

---

## 🚀 Webで無料公開する方法

このアプリは純粋なHTML/CSS/JavaScriptで構成されているため、サーバー契約不要・完全無料で即座に世界中に公開できます。お好みの方法を選んでください。

### 方法1: Netlify Drop（Git不要・ドラッグ＆ドロップで30秒で公開！）★一番カンタン
1. ブラウザで [Netlify Drop](https://app.netlify.com/drop) を開きます（無料アカウント作成またはログイン）。
2. この `tokei-game` フォルダを、ブラウザの画面上にそのままドラッグ＆ドロップします。
3. 数秒で専用のURL（例: `https://happy-clock-12345.netlify.app`）が発行され、スマホやPCからすぐにアクセスできます！

---

### 方法2: GitHub Pages（GitHubをお使いの方におすすめ）
1. GitHubで新しいリポジトリ（例: `tokei-game`）を作成します（Public設定）。
2. このフォルダのファイルをコミットしてプッシュします：
   ```bash
   git init
   git add .
   git commit -m "Initial release of Tokei Master"
   git branch -M main
   git remote add origin https://github.com/<あなたのユーザー名>/tokei-game.git
   git push -u origin main
   ```
3. GitHubリポジトリの **Settings** > **Pages** を開き、Source を `Deploy from a branch`、Branch を `main / root` に設定して **Save** を押します。
4. 数分後、`https://<あなたのユーザー名>.github.io/tokei-game/` で世界中に公開されます！

---

### 方法3: Vercel（GitHub連携またはCLI）
- [Vercel](https://vercel.com/) にログインし、GitHubリポジトリを連携するだけで、自動で独自URL（HTTPS）が無料発行されます。

## 📱 スマホ・タブレットでアプリ化（PWA）する方法

公開されたURLをスマホで開いたあと：

- **iPhone / iPad（Safari）**:
  画面下の「共有ボタン（四角から上矢印が出ているアイコン）」をタップ ➔ **「ホーム画面に追加」** を選択。
- **Android（Chrome）**:
  画面右上の「メニュー（︙）」をタップ ➔ **「アプリをインストール」** または **「ホーム画面に追加」** を選択。

ホーム画面にアプリアイコンが追加され、タップするとSafariやChromeの枠がなくなり、本物のアプリのように全画面で起動します！
